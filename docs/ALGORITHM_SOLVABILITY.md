# Algorithm Solvability & Mathematical Foundations 📐

This document provides a rigorous examination of the mathematical principles governing sliding tile puzzle solvability and explains why PhotoShuffle Pro's scramble algorithm is guaranteed to be 100% solvable.

---

## 1. The Inversion Parity Problem

In a permutation of numbers, an **inversion** occurs whenever a larger number precedes a smaller number.

Formally, for a sequence $A = [a_1, a_2, \dots, a_m]$:
$$\text{Inversions}(A) = \left|\{(i, j) \mid i < j \text{ and } a_i > a_j\}\right|$$

In the solved state $[1, 2, 3, \dots, N^2 - 1]$, the number of inversions is exactly **$0$** (an even integer).

---

## 2. The 15-Puzzle Solvability Theorem

The classic theorem formulated by mathematicians William Woolsey Johnson and William E. Story in 1879 states the exact conditions under which an $N \times N$ puzzle configuration can reach the solved state:

1. **If the grid width $N$ is odd** (e.g. $3 \times 3$):
   - A state is solvable **if and only if** the total number of inversions is **even**.
   - Moving the blank space left or right does not change the order of tiles (inversions $\Delta = 0$).
   - Moving the blank space up or down jumps over $(N - 1)$ tiles. Since $N$ is odd, $(N - 1)$ is even, so the number of inversions changes by an even quantity ($0, \pm 2$). Thus, the parity of inversions remains strictly invariant.

2. **If the grid width $N$ is even** (e.g. $4 \times 4$):
   - Moving the blank space up or down jumps over $(N - 1)$ tiles. Since $N$ is even, $(N - 1)$ is odd, which inverts the parity of the inversion count with each vertical move.
   - Therefore, the invariant is:
     $$\text{Parity} = \left(\text{Inversions} + \text{Blank Row from Bottom}\right) \pmod 2$$
   - A state is solvable **if and only if** this sum is **even**!

### The Half-Solvability Consequence
Because every legal move preserves this parity invariant, the state space of all possible $(N^2)!$ permutations is divided into **two equal, completely disjoint components** of size $(N^2)! / 2$.

If an application generates a puzzle by randomly shuffling the tiles (e.g. using an unconstrained Fisher-Yates shuffle), there is exactly a **$50\%$ probability** that the generated board falls into the unreachable half of the state space! Such a puzzle is physically and mathematically impossible to solve.

## 3. How PhotoShuffle Pro Guarantees 100% Solvability

To eliminate the possibility of impossible puzzle configurations, PhotoShuffle Pro uses a **Reverse Random Walk generator**:

```
[Solved Target State]
        │
   (Valid Move 1)
        ▼
    [State 1]
        │
   (Valid Move 2)
        ▼
       ...
        │
   (Valid Move K)
        ▼
[Scrambled Game State]
```

### Algorithmic Properties:
1. **Connectivity**: Since the starting point is the solved state $S_0$ and every subsequent state $S_{k+1}$ is reached via a valid neighbor shift $S_k \to S_{k+1}$, all intermediate states belong to the same connected component in the puzzle's Cayley graph.
2. **Reversibility**: Because every move in a sliding puzzle is an invertible swap between a tile and the blank space, reversing the sequence of moves $(M_K^{-1}, M_{K-1}^{-1}, \dots, M_1^{-1})$ constitutes a guaranteed mathematical solution path back to $S_0$.
3. **Sufficient Entropy**: By executing $K \ge 120$ transitions (preventing immediate undo transitions), the distribution of tiles is thoroughly randomized while preserving the parity invariant.

## 4. Tile Swap Mode Solvability

In **Direct Tile Swap Mode**, any arbitrary tile can be swapped with any other tile at any time.

In abstract algebra, the symmetric group $S_M$ is generated by all transpositions $(i \ j)$. Any permutation can be factored into a finite sequence of transpositions (cycles):
$$\pi = \tau_1 \circ \tau_2 \circ \dots \circ \tau_r$$

Because the player is permitted to execute arbitrary transpositions, **every permutation in Tile Swap Mode is 100% solvable**.
